## Problem Statement

按 `stock_screen_scores_csi300_l2.csv` 的申万二级权重合计买入代表股，等金额做空沪深 300。本次 office hours 里用 `close.day.bin` 算过：9 月净贝塔约 +0.05，10 月约 -0.09；按贝塔把空头调平后，日残差几乎不动。这两个数没有单独的结果文件，只作为已同意的观察。这张 CSV 要回答的是：哪一个行业的绝对贡献最大。贡献来自代表股收益和该行业成分篮子收益之差。成分是否在篮子里、代表股占行业篮子的份额，不写进这个文件。

## What Makes This Cool

收盘后打开一个日期。若第一行正文的贡献是有限数，第一眼就是绝对贡献最大的那一行，不是整组相对指数的一个数。各行贡献加总后，能和当天「组合收益减沪深 300」对上多少就写多少，对不上的留下，不叫成代表股的错。若每一行贡献都留空，这一天没有「贡献最大」的行。

## Constraints

- 一次一个交易日。第一次跑 2026-10-19。日期写成 `YYYY-MM-DD`。
- `calendars/day.txt` 一行一个日期，编码与所查日期相同，都是 `YYYY-MM-DD`。`close.day.bin` 的第一个数是该序列在这份日历上的起始下标，后面每个数对应该下标起的连续会话。所查日期必须是日历里的一行。上一交易日是该行之前、`SH000300` 收盘为有限数的最近一行。找不到这样的一行：停，不写 CSV。不是该股票自己上一根有数的 K 线。所查日或上一交易日没有有限收盘，该收益就不是有限数。不用更早的收盘去补。
- 代码列都叫 `code`。比较前去掉首尾空白并改成大写。行情文件是 `features/{code 小写}/close.day.bin`。沪深 300 现货代码是 `SH000300`，文件是 `features/sh000300/close.day.bin`。先按这个规则对齐，再判断有没有收盘。`stock_screen_scores_csi300.csv` 里规范化之后的 `code` 出现多于一行：停，不写 CSV。
- 收益、收益差、贡献、贡献合计、组合收益减沪深 300，单位都是小数收益率。0.01 表示 1%。无法计算的行业个数是整数，不是收益率。
- `申万二级名称` 在 l2 表和成分表上，每次比较前都去掉两端空白。只含空白的名称视为空。空名称的 l2 行不进正文，也不进权重分母。空名称的成分行不进任何行业篮子。重复检查和篮子归属都用去掉空白后的名称，因此成分行加入名称相同的那一行正文。去掉空白后同一个非空申万二级名称在 l2 表出现多于一行：停，不写 CSV。
- `所有此申万二级权重` 缺失、不是有限数、或不大于 0 的 l2 行排除，不把无效权重当成 0 加进分母。没有 l2 行进入正文：停，不写 CSV。分母只在原始权重之和大于 0 时才用来除。
- 正文的 `name` 来自 l2 表的 `name` 列，原样复制，包括空白。不读成分表的股票名称。l2 行的 `name` 即使为空，只要去掉空白后的申万二级名称非空且权重有效，这一行仍在正文里。成分行的股票名称为空，不因此把它赶出行业篮子；只要去掉空白后的申万二级名称非空，且权重和收益规则都通过，它就留在篮子里。
- `权重日期` 去掉两端空白后再比较。只含空白视为空。进入正文的行必须是同一个非空日期，否则停，不写 CSV。写出的是去掉空白后的那个日期。每一行正文和表底都写它。这份表预期是 2026-09-30。
- 行业权重的分母是全部正文行的「所有此申万二级权重」之和，包括代表股收益留空的行。展示的行业权重是该行权重除以这个分母，正文行业权重之和为 1。贡献用这个展示权重，不再做第二次归一。
- 行业成分来自 `stock_screen_scores_csi300.csv`，按去掉空白后的申万二级名称归入对应正文行。「权重」缺失、不是有限数、或不大于 0 的成分行不进篮子。当天收益不是有限数的成分行也去掉，篮子里其余权重重归一。代表股若也在成分里，只按它自己的指数权重进入篮子。剩下权重之和不大于 0 时，行业成分收益留空。
- 收益差 = 代表股收益 − 行业成分收益，只在两项都是有限数时填写。贡献 = 展示的行业权重 × 收益差。代表股收益不是有限数：代表股收益、收益差、贡献留空；行业成分收益在篮子算得出来时仍填写。行业成分收益留空：收益差和贡献留空。贡献留空的正文行仍留在表里，不进贡献合计，并计入无法计算的行业个数。
- 组合收益只对代表股收益为有限数的正文行，用它们的展示行业权重再归一后加权。这些行里行业成分收益留空的，只要代表股收益有限，仍进入组合收益。这样的行一个都没有，或 `SH000300` 的当天收益不是有限数：表底「组合收益减SH000300」留空，不用期货价格代替。`SH000300` 的收益用同一对交易日的现货收盘。
- 贡献合计是有限贡献之和。
- 排序只排正文：有限贡献按绝对值从大到小，绝对值相同按申万二级名称字典序。贡献留空的排在所有有限贡献之后，同样按申万二级名称。表底不参与排序，固定在正文后面。
- 第一行正文的贡献是有限数时，这一行才叫「贡献最大」。每一行贡献都留空时，这一天没有「贡献最大」的行。
- 每一行正文的 `记录类型` 写 `body`。`无法计算的行业个数` 在每一行正文留空。
- 表底恰好三行，`记录类型` 为 `footer`，不进排序。`申万二级名称` 依次是 `贡献合计`、`组合收益减SH000300`、`无法计算的行业个数`。前两行的数写在 `贡献` 列，第三行的 `贡献` 留空。个数只写在第三行的 `无法计算的行业个数` 列，前两行该列留空。没有单独规定取值的表底格子一律留空。
- 列：`记录类型`、`code`、`name`、`申万二级名称`、`行业权重`、`代表股收益`、`行业成分收益`、`收益差`、`贡献`、`权重日期`、`无法计算的行业个数`。文件先有一行这些列名，再是正文，再是恰好三行表底。正文行数等于通过名称和权重规则的行业数，不写成固定的 79，也不把表头和表底算进行数。
- 不改期货张数，不发订单。按贝塔算张数不出现在 CSV 里。
- 脚本是 `scripts/csi300_l2_day_gap.py`。不写进 pyproject 的命令入口，不成为 `ashare-daily` 子命令，不写测试。输入路径和日期 2026-10-19 写在脚本里。读 `close.day.bin` 的小段逻辑抄进这个脚本，不调用 `csi300_l2_hedge` 里以下划线开头的函数。
- 每一种「停，不写 CSV」都向 stderr 打一行原因，退出码为 1。不写出半份文件。
- 输出 CSV 放在 l2 表旁边，文件名带日期。

## Premises

1. 这张表不改期货订单。空头仍按股票市值等金额做空沪深 300。美国账本用贝塔算张数。这里只把「按贝塔再算一次张数」记成对照，不拿它当这张表的动作。9 月净贝塔约 +0.05、10 月约 -0.09，以及「调平贝塔几乎不改变日残差」，来自本次 office hours 对 `close.day.bin` 的计算，没有单独的结果文件。
2. 每一行的贡献等于展示的行业权重乘以收益差。收益差是代表股当天收益减去该行业成分篮子的当天收益。各行相加，是股票替换解释的那一截。它和「组合收益减沪深 300 收益」的差，不命名成代表股的错。
3. 权重用打分表上的截面。进入正文的行必须共享同一个去掉空白后的非空权重日期；这份表预期是 2026-09-30，不是该交易日中证指数重新公布的权重。一次只看一个指定的交易日。不发订单。不沿用 2015 年走廊，也不沿用 10 只低波动那份设计。

### R2-1 — consistency

**Problem**

> 申万二级名称 is not one key. An l2 row is dropped when the name is empty after 去掉空白, a constituent row is dropped only when 申万二级名称为空, and both the duplicate-name stop and the basket join compare the raw name. A trailing space can therefore pass as its own industry, miss the constituent basket, and blank that row's industry return.

**Remedy**

> Trim both ends of 申万二级名称 on the l2 file and on stock_screen_scores_csi300.csv before every test. A whitespace-only name is empty. Use that trimmed name for the l2 duplicate stop and for basket membership, so a constituent joins the one l2 row with the same trimmed name.

### R2-2 — clarity

**Problem**

> A constituent row with a blank stock name and a non-empty 申万二级名称 is not kept in or removed from the basket. The l2 rule keeps such a stock in the body, and the constituent rule only lists an empty industry name, a bad 权重, and a non-finite return as drops.

**Remedy**

> State that a blank stock name does not remove a constituent from its industry basket when the trimmed 申万二级名称 is non-empty and the weight and return rules pass.

### R2-3 — consistency

**Problem**

> The problem statement asks which industry's representative left that industry's real CSI 300 constituents. The committed columns and The Assignment show code, 申万二级名称, 收益差, and 贡献, which do not show constituent membership or the representative's share of the industry basket.

**Remedy**

> Rewrite the problem statement to the question the CSV answers: which industry has the largest absolute contribution from the representative-versus-basket return gap. Leave membership and weight share out of this file.

### R2-4 — completeness

**Problem**

> A repeated l2 industry name stops the run, but a repeated constituent code does not. Two rows with the same code would both enter the renormalized basket, or the same stock would enter two industries, and change 行业成分收益.

**Remedy**

> If the same normalized code appears on more than one row of stock_screen_scores_csi300.csv, stop and do not write the CSV.

### R2-5 — completeness

**Problem**

> If no l2 row enters the body, the displayed-weight denominator is an empty sum, while the weight rule still says the displayed industry weights sum to 1. The date rule does not explicitly stop on an empty set of body rows.

**Remedy**

> If no l2 row enters the body, stop and do not write the CSV. Divide by the raw-weight sum only when that sum is positive.

### R2-6 — clarity

**Problem**

> 收益差 is required on the first body row and is blanked when either return is non-finite, but its value when both returns are finite is never defined. The subtraction appears only inside the contribution formula.

**Remedy**

> Define 收益差 as 代表股收益 minus 行业成分收益, written only when both are finite, and define 贡献 as the displayed 行业权重 times 收益差.

### R2-7 — consistency

**Problem**

> The output rule sets the row count equal to the number of industries that pass the name and weight rules, while the same file also has a header and three footer rows.

**Remedy**

> State that this count is the body only. The CSV also has one header row naming the committed columns, then exactly three footer rows.

### R2-8 — clarity

**Problem**

> Footer rows set 记录类型 to footer. Body rows never receive a 记录类型 value.

**Remedy**

> Write body as the 记录类型 of every body row.

### R2-9 — clarity

**Problem**

> Footer rules fill 申万二级名称, 权重日期, 贡献 on the first two footer rows, and 无法计算的行业个数 on the third. They do not say what the remaining footer cells contain, or that body rows leave 无法计算的行业个数 blank.

**Remedy**

> Leave every footer cell without a stated value blank, including 贡献 on the count row and 无法计算的行业个数 on the first two footer rows. Leave 无法计算的行业个数 blank on every body row.

### R2-10 — clarity

**Problem**

> A body row's 权重日期 must be exactly one non-empty value, but unlike code and 申万二级名称 the date is not trimmed. A trailing space makes two otherwise identical dates disagree and stops the CSV, or writes a padded date.

**Remedy**

> Trim 权重日期 before the check. Whitespace-only is empty. Stop unless every body row has the same one non-empty trimmed date, and write that trimmed date.

### R2-11 — clarity

**Problem**

> 贡献最大 is defined as the largest absolute contribution, and therefore the first body row. Blank contributions sort last, so when every contribution is blank the first row is only a name-order row and is not an absolute maximum.

**Remedy**

> Call the first body row 贡献最大 only when its contribution is finite. When every body contribution is blank, say the day has no 贡献最大 row.

### R2-12 — clarity

**Problem**

> The blank-stock-name rule says 股票名称, and the body schema has name, but neither input file's stock-name column is named. Body name could be copied from the l2 row or from the constituent row.

**Remedy**

> Name the l2 column that supplies body name and copy that cell unchanged, including blank. Do not read the constituent file's stock name for the body.

### R2-13 — feasibility

**Problem**

> The previous trading day is the latest calendars/day.txt session before the queried date with a finite SH000300 close. The line format, the date encoding shared with the query and with close.day.bin, and the result when no such session exists are unspecified.

**Remedy**

> State the day.txt line format and the date encoding used to match a calendar session to the requested date and to a close.day.bin bar. If no earlier session has a finite SH000300 close, stop and do not write the CSV.

A constituent with a blank stock name and a non-empty 申万二级名称 is still not explicitly kept or dropped.
