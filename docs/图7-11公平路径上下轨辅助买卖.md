## 1. 图上三个量怎么读

| 量 | 含义 | 常见误读 |
|---|---|---|
| **公平路径** `path[t]` | 该窗口滚动 log OLS 在 t 的高度（**红虚线** y） | ≠ 公允价值保证 |
| **路径年化 `g[t]`** | 同窗口斜率年化 `exp(b·252)−1`（悬停「当日路径年化」） | ≠ 过去两年实现 CAGR |
| **实现年化 CAGR** | 同窗口端点 `(P_T/P_0)^(252/n)−1`：图例是**末日**值；悬停「当日实现年化」是**该日因果**窗端点 | ≠ 历史价格路径 |
| **上下轨** | `upper/lower = path · exp(±δ)`，`δ=P95(|ln(c/p)|)` 因果扩展 | ≠ 硬止损；极端日可刺穿 |
| **相对路径因果分位** | 悬停：`|ln(c/path)|` 在历史≤t 的经验分位，path 上为正、下为负 | ≠ 收益分位；`±P95` 约等于贴上/下轨 |

图7–11 只是窗口不同（2年 / 1年 / 6个月 / 3个月 / 1个月），**不是五套独立系统**。上市以来 HTML 上还有 EWMA 轨，见路径说明；checklist 的触轨仍对 expanding P95。

## 2. 每日操作顺序（5 步）

1. **主图**：`regime` + 绿/红三角（生产权威）。
2. **图7–8**：长尺 `g`、path 是否仍抬升 → 是否允许「向路径回归」叙事。
3. **图9–10**：价 vs path / 上下轨 → 深折价 + 止跌，或近上轨减仓。
4. **图11**：只看近端节奏，**不单独触发买卖**。
5. **ED / RU**：ED 降权；RU 支持修复叙事，仍需短尺收复 path 才考虑加仓。

## 4. 买入 checklist（弱 → 强 · 完整档含 B4–B6）

勾选越多，辅助观察越强；**满分为研究级，不等于生产 BUY**。  
日常扫描以 **§3（B123）** 为准。

| # | 条件 | 图/数据 | 通过标准（代码默认） |
|---|---|---|---|
| B1 | 深折价或触轨 | 图9/10 | 收盘 ≤ 下轨，或相对图8 path 折价 ≤ −15% |
| B2 | 长尺未坏 | 图7 或 图8 | `g > 0`，或 path 近 20 日仍抬升。上市不足约 1.9 年不看图7 |
| B3 | 短尺止跌 | 图10 或 图11 | 收盘 ≥ 对应 path，或图10 昨触下轨、今收回 |
| B4 | 无冲突 / 有修复 | 主图 + ED/RU | 无 ED。`down` 且无 RU → 不通过。`range` 且无 RU → 不通过。`up`，或有 RU，才通过 |
| B5 | R:R 合格 | 图8/10 path + ATR | 止损 = 买价 − 1×ATR20（无 ATR 时用买价×0.94）；目标回到图8 或图10 path；R:R ≥ 2 |
| **B6 生产确认** | hold_up | 主图 | **绿三角 / regime→up** → 才是生产买点 |

**默认动作映射**

| 通过项 | 建议 |
|---|---|
| B1+B2，无 B3 | 观察，不建仓 |
| B1+B2+B3，无 B6 | 辅助观察，不升生产仓 |
| B1–B5 + B6 | 与生产一致，按 hold_up |

## 6. 明确禁止

- 单看图11（1 个月）决定买卖。
- 只因「在 path 下方」买入（折价 ≠ 买点）。
- 把 P95 轨当硬止损（设计上允许刺穿）。
- 用图例期末 `g≈…%` 代替**当日** hover 的 `当日路径年化`。
- 未复权价与 HTML（前复权）混算 path / 轨。
- 用辅助信号覆盖或删除生产三角。
- 把 ETF 池回测胜率当成这批股票的期望。

## 7. R:R 快速算（辅助观察，不是下单公式）

```text
Reward% = 目标价 / 买价 − 1    （目标价 = 图8 或图10 path）
Risk%   = 买价 / 止损价 − 1    （止损价 = 买价 − 1×ATR20；无 ATR 时买价×0.94）
R:R     = Reward% / Risk%      （代码默认 ≥ 2 才记 B5）
```

B5 只给 `strong_aux_buy` 加分。没有 B6 时，它仍然不是生产买点。
