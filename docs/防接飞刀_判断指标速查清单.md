# 防接飞刀判断指标速查清单

> **身份：读图对照，不改生产。** 生产买卖仍以 `hold_up` 为准。这里的 B1 是图7–图11 的辅助触发，不是绿三角。
>
> 列来自 `compute_multi_scale_frame` + `enrich_frame_for_checklist`（`src/ashare_daily/lib/fair_path_band_signals.py`）。路径定义见 [路径说明.md](路径说明.md)。连续 10 日破 fig10 在六状态里叫②，见 [六状态趋势划分.md](六状态趋势划分.md)。
>
> 快/慢形态和下面的斜率过滤，是读图顺序，不是个股上标定过的买卖阈值。ETF 单票稿里的具体日期、涨幅例子没有迁入。个股有涨跌停，同样的百分比会在更少的交易日里走完。

## 总原则

先判断这轮下跌是「暴涨后的急转」还是「慢慢滚下来的」。急转看短尺还在不在跌、价格有没有持续留在 3 个月路径下面；慢跌看 6 个月和 3 个月斜率是不是一起向下，以及中轨锚还在不在下沉。

任何情况下，只有 B1、没有 B2，代码结论是 `avoid_falling_knife`，不能买。跌完没有，按「收复路径 → 短尺斜率收敛 → 短尺斜率转正」看，不抢跑。

## 第一步：下跌形态（快 vs 慢）

用价格自己看，不另造指标。`px` 是前复权收盘。

| 看见什么 | 当成 | 为什么 |
|---|---|---|
| 近端有一段很快的上涨，3–6 个月窗口还被那段涨幅顶住：价格已经在跌，fig10_g 仍很大 | **快** | 中周期斜率被污染，fig10_g / fig9_g 暂时不能当「还在涨」 |
| 顶部是横盘或缓涨滚出来的，窗口里没有那段脉冲 | **慢** | 窗口干净，双斜率可以用 |

没有一个已经在个股上重估过的涨幅百分比。不要把某次 ETF 行情里的「近 1～2 个月 +20%」抄成硬门槛。

## 第二步：B1 触发（代码默认）

`evaluate_checklist_row` 里 B1 为真，当且仅当下面任一成立：

- `fig9_touch_lo` 或 `fig10_touch_lo`（收盘 ≤ 该图 expanding P95 下轨）
- `fig8_gap` ≤ −15%（`DEFAULT_DEEP_GAP = -0.15`，研究默认，未在个股上重估）

B1 之后必须有 B2 才谈回归：图7 或图8 的 `g > 0`，或对应路径近 20 日仍在抬升。上市不足约 1.9 年时不看图7。B2 不过 → 不买。

不要用更长的 fig7_g / fig8_g 代替下面的刀锋过滤。长尺为正，只说明大背景还没坏，不说明这轮下跌已经结束。

## 第三步：刀锋过滤（B1 且 B2 之后仍要看）

| 形态 | 仍不买 | 对应列 |
|---|---|---|
| 快 | `fig11_g` ≤ 0，或收盘持续留在 fig10 路径下 | `fig11_g`、`px` vs `fig10_path` |
| 慢 | `fig10_g` ≤ 0 且 `fig9_g` ≤ 0 | `fig10_g`、`fig9_g` |
| 慢，再加一道 | `fig9_path_rising` 为 False（fig9 路径相对 20 日前没有抬升） | `fig9_path_rising` |

「持续留在 fig10 路径下」在六状态里有一个代码定义：连续 **10** 日收在 fig10 路径之下 = ②急跌刀锋（`_KNIFE_BARS`）。这是状态名，不是「个股此时应该空仓」的证明。见六状态文档。

## 第四步：解除警报（不抢跑）

三步都用当日收盘能算出的量，按顺序看，缺一步就不把辅助观察升级。

| 步骤 | 指标 | 确认 | 语义 |
|---|---|---|---|
| ① 止跌 | `px` vs `fig10_path` | 收盘站回 3 个月路径上方 | 跌势暂停，可以反复 |
| ② 动能耗尽 | `fig10_g` | 从深负值持续收窄，不要求单日翻正 | 下跌动能在衰竭 |
| ③ 趋势结束 | `fig10_g` | 3 个月年化斜率转正 | 这条短尺上的下跌斜率结束 |

fig9_g 转正不是这三步的必要条件。6 个月尺可以仍为负，那只说明修复还没传到更长的窗口，仓位上留余地。

即便三步都过，也只是辅助观察。生产买点仍是主图进入上涨态。

## 汇总决策表

```text
价格触发 B1（图9/图10 触下轨，或图8 折价 ≤ −15%）
        │
        ▼
   B2 不过（长尺 g 与路径都不抬升）→ 不买
        │ B2 过
        ▼
近端是急转，还是慢滚？
   ├─ 快 → fig11_g ≤ 0，或持续收在 fig10 路径下？→ 是：不买
   └─ 慢 → fig10_g ≤ 0 且 fig9_g ≤ 0？→ 是：不买
            └─ fig9 路径近 20 日仍在下坡？→ 是：不买
        │ 全部通过
        ▼
   辅助观察。加仓仍要等短尺收复（B3：站回图10/图11 路径，或图10 昨触下轨、今收回）
        │
        ▼
持有期间：收复 fig10 路径 → fig10_g 收敛 → fig10_g 转正
正式离场仍看红三角
```
